## ✨ Project Overview

**Fundamental Booster** is an Excel practice and analysis workbook designed to strengthen core spreadsheet skills through realistic, structured datasets. It uses formulas to calculate results, apply logical conditions, summarize information, and present key metrics in an easy-to-understand format.

The workbook is organized into five worksheets, each focused on a different part of the analysis process.

## 🗂️ Workbook Structure

| Worksheet | What it covers |
|---|---|
| 🎓 **Students Grade** | Subject marks, total scores, averages, grade classification, and logical checks |
| 💰 **Sales Data** | Product sales, regions, salespeople, dates, discounts, and net amounts |
| 👥 **Employee Data** | Employee details, departments, salaries, joining dates, tenure, and salary bands |
| 📌 **Pivot Tables** | Formula-driven summaries of sales by region and product, plus product-level metrics |
| 📈 **Analysis** | Key performance indicators and visual summaries for sales, employees, and students |

## 🧰 Excel Skills Demonstrated

### 🧮 Formula & Calculation Skills
- `SUM` and `AVERAGE` — calculate totals and averages
- `MIN` and `MAX` — identify minimum and maximum values
- `ROUND` — round calculated results
- `COUNT` and `COUNTIF` — count numeric values and records matching a condition

### 🧠 Logical Functions
- `IF` and nested `IF` — assign grades, discounts, salary bands, and status labels
- `AND` — check whether multiple conditions are true
- `COUNTIFS` — count records using multiple criteria
- `SUMIFS` — calculate totals based on conditions

### 🔎 Lookup & Reference
- `INDEX` + `MATCH` — retrieve matching information dynamically
- Formula-driven summaries — identify leading regions, products, and salespeople

### 📅 Text & Date Functions
- `TEXT` — format dates and extract readable month or weekday names
- `YEARFRAC` — calculate employee tenure
- `FIND` and `LEFT` — useful text-extraction techniques for spreadsheet tasks

### 📊 Reporting & Analysis
- Region-by-product sales summaries
- Product-level sales count, total, average, and share of total
- KPI calculations for sales performance
- Charts and visual summaries for quicker interpretation

## 🔍 What the Workbook Helps Answer

- What are each student's total and average marks?
- Which grade should be assigned based on the average?
- How do sales vary across regions and products?
- What discount applies to a sale, and what is the net amount after discount?
- Which products contribute to sales performance?
- How can employee tenure and salary categories be calculated?
- Which key metrics help summarize the overall dataset?

## 🚀 How to Use

1. Download `PR1_Fundamental_Booster.xlsx`.
2. Open it in **Microsoft Excel**.
3. Explore each worksheet using the tabs at the bottom.
4. Review the formulas in calculated columns to understand how the results are produced.
5. Change input values carefully and observe how formula-driven summaries respond.

> **Tip:** Some summary tables are built with formulas rather than Excel's native PivotTable feature. Keep source ranges and criteria consistent when updating the data.
